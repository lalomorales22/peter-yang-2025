# Peter Yang Gets Organized

An iOS app built with SwiftUI to help track daily tasks and build consistent habits. The app includes a unique achievement system that gradually unlocks a Bitcoin address as you maintain your daily streak.

## Features

- **Daily Task Management**: Track morning and evening tasks
- **7-Day Progress Chart**: Visual representation of your task completion rate
- **Achievement System**: Unlock a Bitcoin address piece by piece
  - Complete tasks for 100 consecutive days to unlock the first segment
  - Continue for 1000 days to reveal the full address
  - Visual progress tracking with dual progress bars

## Requirements

- iOS 15.0 or later
- Xcode 13.0 or later
- Swift 5.5 or later

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/lalomorales22/peter-yang-2025.git
   ```
2. Open `PeterYangGetsOrganized.xcodeproj` in Xcode
3. Build and run the project

## Usage

1. **Daily Tasks**: Check off your daily tasks as you complete them
2. **Stats View**: Monitor your progress with the 7-day completion chart
3. **Achievement Tracking**: Watch as you unlock portions of the Bitcoin address by maintaining your daily streak
